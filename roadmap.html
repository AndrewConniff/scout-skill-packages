Curated Delivery Roadmap

From customer pursuit to curated assets: this sequence shows how one information stream drives deck curation, demo package generation, and web-first walkthrough publishing.

1. Customer Win room

Initial pursuit context and solution intent are aligned by the team.

2. Customer Scoping call (MTT in attendance)

Customer requirements, audience profile, and delivery constraints are captured with the MTT.

3. Information gathered

Inputs are normalized into a structured package used by every downstream build path.

4A. PPTX Deck Curation flow

Curated slide assets are extracted, ranked, and assembled into targeted delivery decks.

4B. Demo-builder flow (Scout / Cowork)

The same source information drives multi-format artifact generation.

5. HTML walkthrough + GitHub publish

Original information is also transformed into a web walkthrough (HTML5), then published with all files and demos under a class welcome page.
